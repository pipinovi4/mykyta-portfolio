# Repository Instructions

- The frontend application lives in `frontend/`.
- Use Next.js App Router, strict TypeScript, and Tailwind CSS.
- The initial version is a static frontend skeleton.
- Do not add backend functionality yet.
- Do not modify Docker Compose, Nginx, CI, or deployment infrastructure unless explicitly requested.
- Keep project and profile content separate from UI components.
- Do not invent employers, clients, metrics, testimonials, or project results.
- Use semantic HTML and accessible keyboard navigation.
- Support responsive layouts starting at 360px.
- Respect `prefers-reduced-motion`.
- Run linting, TypeScript checks, and a production build before finishing.
